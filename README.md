# 🐍 Snakeeyes Stremio Catalog

A custom Stremio catalog addon featuring curated collections for Movies, TV Shows, Directors, and Decades. Powered by TMDB.

## Install

Click below to install directly in Stremio:

**[stremio://https-snakeeyes-github-io.onrender.com/manifest.json](stremio://https-snakeeyes-github-io.onrender.com/manifest.json)**

Or paste this URL directly into Stremio's addon install field:

```
https://https-snakeeyes-github-io.onrender.com/manifest.json
```

You can also visit the [landing page](https://https-snakeeyes-github-io.onrender.com) for a one-click install button.

## What's Included

- Movie Collections (Popular, Award Winning)
- Kids Zone
- Documentaries
- 80s, 90s, 00s Decades
- Drama & Comedy Series
- Horror & Supernatural Shows
- Director Collections (Christopher Nolan, Quentin Tarantino)
- Actor Collections (Leonardo DiCaprio, and more)

## Notes

- Catalog data is pulled live from TMDB
- Hosted on Render.com free tier — first request after inactivity may take 30-60 seconds to wake up

## Tech Stack

- Node.js / Express
- Hosted on Render.com
- TMDB API for catalog and metadata
